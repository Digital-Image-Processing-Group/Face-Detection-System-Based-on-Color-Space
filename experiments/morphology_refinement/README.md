# 形态学调整实验

从 `full-project` 创建独立分支 `codex/morphology-refinement`，比较减弱闭运算、提前填洞、候选尺度自适应。颜色模型和距离平方阈值4保持不变。原 GUI 和提交版入口保留原算法；本实验通过下面的脚本运行。

## 实际结果

100张验证图比较24组配置后，选中候选短边1%的开运算核、相对开核1.8倍的闭运算核，并在几何筛选前填洞。核尺寸取奇数并限制在1至101。验证集累计人脸IoU从0.5267升到0.5393，之后冻结配置，在原尺寸上比较79张输入。

| 集合 | 原平均人脸IoU | 新平均人脸IoU | 变化/百分点 | 原累计IoU | 新累计IoU |
|---|---:|---:|---:|---:|---:|
| 测试人像24张 | 0.5878 | 0.6135 | +2.57 | 0.5977 | 0.6054 |
| 其中正脸8张 | 0.6816 | 0.6820 | +0.03 | 0.6606 | 0.6609 |
| 其中侧脸16张 | 0.5409 | 0.5793 | +3.83 | 0.5376 | 0.5533 |
| 复杂人脸场景33张 | 0.1482 | 0.1324 | -1.58 | 0.1473 | 0.1499 |

测试人像平均提升主要来自 `hfd_5_AFA8`：原方法没有保留人脸候选，新方法IoU为0.6332。其余23张的平均IoU变化为-0.08个百分点。按0.5个百分点作为变化界限，24张中5张提升、4张下降、15张变化较小。

复杂场景累计IoU略升，但逐张平均IoU下降。累计IoU按总像素计数，大区域的变化影响更大；这些结果表明收益集中在少量图片，尚未形成普遍提升。20张无脸验证背景中，误检由9张增加到11张，即45%升至55%；两张手部裁剪仍均有误检。背景中的动物属于无脸负样本，没有用于肤色模型训练。

## 各项改动

每组均按验证集累计IoU选择配置，表中为最终对照集逐张平均IoU。候选尺度组允许同时选择提前填洞，因此该行是组合方法的结果。

| 方法 | 测试人像 | 复杂人脸场景 |
|---|---:|---:|
| 原方案 | 0.5878 | 0.1482 |
| 仅减弱闭运算：参考核9改为5 | 0.5842 | 0.1355 |
| 仅提前填洞 | 0.5878 | 0.1390 |
| 减弱闭运算＋提前填洞 | 0.5842 | 0.1362 |
| 候选尺度自适应＋提前填洞 | 0.6135 | 0.1324 |

单独减弱闭运算没有改善这批图片；提前填洞也没有改善24张测试人像。选中的组合可以补回部分原本被丢弃的候选，同时也保留了更多背景。保留本分支用于研究和对照，原始完整版仍作为稳定版本。

## 复现和单图运行

使用原仓库环境并完成数据恢复后，在仓库根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/compare_morphology.py validate
.\.venv\Scripts\python.exe scripts/compare_morphology.py evaluate
```

验证结果写完后才开始评估。若只处理自己的照片，直接使用本分支保存的冻结配置：

```powershell
.\.venv\Scripts\python.exe scripts/compare_morphology.py predict --image "图片路径" --output "输出目录"
```

输出原尺寸二值人脸掩膜和绿色分割叠加图。实验代码在 `src/segmentation/morphology_refinement.py`，其余几何阈值继续使用 `config/pipeline.json`。自适应方法先按原始肤色连通域分开处理，小于最低候选面积四分之一的碎片预先移除；填洞单洞上限仍是原候选前景面积的30%。

本目录保存冻结配置、验证汇总、逐图CSV、结果汇总和核查记录。55项测试通过；原方案在所有79张输入上的计数与原报告一致；肤色掩膜逐像素不变；158份预测掩膜读回一致；单张图片入口也与批量预测逐像素一致。
