1. B 使用四元组返回、`distance_threshold` 及 dict bbox；当前统一为任务书字典结果，保留 dict bbox 并说明半开边界，采用 `distance_squared_threshold`。旧阈值字段只作兼容别名。
2. B 原配置 T=20 没有验证集选参记录；新增只读验证集的独立校准工具，两模型各选参数，保存完整候选和冻结哈希。
3. 模型增加原始协方差对称、半正定及正则后正定检查；配置增加有限值、范围、奇数核和版本绑定检查。
4. B 原填洞上限相对于整图面积，可能对小候选填入过大孔洞；改成相对于各候选前景面积。候选 area 更新为填洞后的实际像素数。连通域运算在 ROI 内完成，避免为每个候选重复创建整图数组。
5. 后处理支持参考短边缩放核，全部输出仍按原尺寸计算；校准比较原 B 固定尺度及两组随分辨率变化的尺度。保留所有通过筛选的区域，不新增神经网络检测器。
6. 原数据恢复偶发 TLS 中断；增加有限次数重试，继续执行原哈希校验和缺失恢复，不更改原图来源。
7. 模型按本轮 Windows 安装文件字节绑定 SHA256；`.gitattributes` 显式固定该模型的 CRLF 检出格式，避免 Git 自动换行导致重新克隆后错配。标注则同时核对冻结参考及像素内容，区分 PNG 压缩字节漂移。
